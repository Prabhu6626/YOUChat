# Security Policy

## Supported Versions
Currently, we only support the latest deployed version of YOUChat. 

## Reporting a Vulnerability

Security is a core priority for YOUChat, given its End-to-End Encryption architecture. 

If you discover a security vulnerability within YOUChat (e.g., broken encryption, exposed WebSocket events, unauthorized database access), please **DO NOT** create a public GitHub issue. 

Instead, please send an email to our security team confidentially:
**security@youchat.local**

Please include:
1. A detailed description of the vulnerability.
2. Steps to reproduce the issue.
3. Any potential impact or proof of concept.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.

Thank you for helping keep YOUChat safe and secure!
